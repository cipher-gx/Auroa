#  Auroa - Sistema Inteligente de Gestión Financiera

![Spring Boot](https://img.shields.io/badge/Spring_Boot-F2F4F9?style=for-the-badge&logo=spring-boot)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-316192?style=for-the-badge&logo=postgresql&logoColor=white)
![Java](https://img.shields.io/badge/Java-ED8B00?style=for-the-badge&logo=openjdk&logoColor=white)

**Auroa** es una plataforma de gestión financiera personal diseñada para brindar luz y claridad sobre tus finanzas. A diferencia de las aplicaciones tradicionales, Aurora está estructurada para manejar casos de uso del mundo real: fechas de corte de tarjetas de crédito, deudas a terceros (préstamos), presupuestos cíclicos y captura inteligente de tickets mediante OCR.
